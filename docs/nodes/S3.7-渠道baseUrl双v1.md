## 输入

- 现象：`baseUrl` 自带 `/v1`（如 Ollama Cloud `https://ollama.com/v1`）时，代转发目标变 `/v1/v1/models` → 上游 404。
- 根因（行号以 `git show bc5705d:<path>` 为准）：
  `web/src/services/api/channel-proxy.ts:46-52` 用「相对 origin 的完整 pathname」当 subpath；
  `wanrepro/ui/channel_store.py:695` 又用 `base.path + "/" + subpath` 拼一次 → 双拼。
