# 内容治理判据（G1–G7，分级版）

> 状态：v1 · 2026-11-19 · 依据《方案-内容治理GEO-20261119.md》v3 §一/〇c 收敛后版本。

## 一手来源（调研原文，非转述）

1. **GEO: Generative Engine Optimization**（KDD'24, arXiv 2311.09735）——内容可切片 + 显式引用来源这两条手段对口；关键词密度/FAQ schema/llms.txt/citation bait **不采纳**（面向站点爬虫，非本地文件）。
2. **Anthropic「Skill authoring best practices」**（platform.claude.com/.../agent-skills/best-practices）——context window 是公共资源；progressive disclosure；只补模型不知道的。
3. **kapa.ai「Writing documentation for AI」**——AI 按 chunk 读，每块必须自含。
4. **docmd「Deterministic and Chunkable Docs」**——每个 `##`/`###` 一个原子概念；警告与命令物理相邻。
5. **Amplitude「Structuring Documentation for AI Readers」**——一篇文档不混内容类型；拆小+互链；句子 <30 词。
6. **agentskills.io 规范**——SKILL.md + references/ + scripts/ + assets/；description 含检索关键词。

## 判据分级总览

| 级别 | 含义 | 判据 |
|---|---|---|
| **硬门（S 系）** | 本轮改动必须全绿才落盘，FAIL=未完成 | S1 片段守恒 / S1b 反向注入 / S2 移动句计数 / S3 裸段落不新增 / S4 字节上界 / S5 头 5 行 / S6 悬空指代 / S7 标题数字一致 / S8 体检清单产出 |
| **脚本清单可判** | 机器出清单，超标只登记不擅改 | **G4 / G5 / G7** |
| **人判** | 需逐条人工判定，grep 仅辅助 | **G1 / G2 / G3 / G6** |

## 脚本清单可判（本轮已跑 20 文件，见《内容治理体检-20261119.md》）

| # | 判据 | 判法 | 分级 |
|---|---|---|---|
| **G4** | **原子长度**：单块 ≤ 1,500 字符；超了拆成并列条，每条自带主语（保留原编号） | 脚本按行量长度，输出超标行号+字节数 | **house rule（无外部来源）** |
| **G5** | **句子偏短**：目标 ≤ 30 词/≈60 汉字（**软判据**，存量长句只登记不改写） | 脚本按 `。！？` 切句统计汉字数 | sourced（Amplitude：句子 <30 词） |
| **G7** | **头 5 行声明**：用途 / 边界 / 读法（/ 来源 / 交叉引用） | 脚本逐文件断言头 5 行关键词 | **house rule（无外部来源）** |

## 人判（抽检，不进脚本门）

| # | 判据 | 判法 | 分级 |
|---|---|---|---|
| **G1** | **一个文件一种内容类型**（reference / how-to / explanation 不混） | 人工判定 + 头 5 行声明类型 | sourced（Amplitude） |
| **G2** | **一节一概念**：每个块只讲一主题；标题或首句加粗锚含检索关键词 | 人工抽检 | sourced（docmd + kapa.ai） |
| **G3** | **块自含**：块内不得有跨块悬空指代（「见上文」「如前所述」「该功能」「它」）；跨文件引用一律写显式文件名 | grep 悬空指代词 + 人工逐条判定（grep 抓「它」必然大量误报，故归人判） | sourced（kapa.ai） |
| **G6** | **检索锚**：每条至少含一个唯一锚点（函数名/环境变量/错误码/文件路径/命令） | 脚本抽检 + 人工确认锚是否真唯一 | **house rule（无外部来源）** |

## 使用规则

- **硬门（S 系）只约束本轮及后续拆分/搬运动作**，不约束存量内容。
- **G4/G5/G7 脚本超标 = 登记进体检清单**，留给下一批处理，不在本轮擅改。
- **G1/G2/G3/G6 由人抽检**，grep 输出只作线索不作结论。
- 三条 house rule（G4/G6/G7）是本仓自定家规，引用时不得冒充外部 sourced。
