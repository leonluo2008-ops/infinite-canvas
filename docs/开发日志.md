### 工程结论（已转成规则）

1. **图床/媒体出口必须国内直连**：Cloudflare 隧道在本机网络下落 lax，跨境往返导致大文件超时与被边缘 502；「源站已回 200 但客户端 502」是隧道回程断链的标准形态。→ 适配包红线 11 + §3.1 排障口径。
2. **事实型状态不得占用红色错误位**：把「还没填 key」写进 `error` 会造成永不清除的「保存失败」横幅（本次实测触发所有者明确否决）。→ 适配包红线 12。
3. **代转发必须支持 chunked**：Cloudflare / HTTP/2 转发常有 `Transfer-Encoding: chunked`，只认 `Content-Length` 会把正常请求打成 411。（属可推导实现细节，不落规则，`2455bb3` 已实现。）
4. **大字节上传路径不可依赖长链路**：先瘦身（参考图 1600/JPEG 0.85）+ 对 5xx 重试，是低成本兜底而非根治；根治是把字节发到国内主机。→ 适配包 §3.1「兜底与根治」。
