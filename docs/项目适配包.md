## 1. 项目是什么

把 `infinite-canvas`（KunrouAI 开源无限画布）从单机版改造成**多用户 SaaS**：账号体系 + 服务端渠道持久化（BYOK 自带密钥）+ 数据按用户隔离 + 服务端代转发。
路线 **C（BYOK）→ B（预留）**，一期砍掉 Agent 多租户。
所有者哲学（原话）：「不想用户端太重，基本上所有的后端服务都在服务器上处理」。
不做：Agent 多租户、积分计费、协作画布、渠道共享。

## 7. 红线

1. **渠道单一权威源**：登录态渠道列表以 `GET /api/user/channels` 为准；本地持久化中的渠道数据不参与显示、不参与合并、不参与任何决策。判据：换账号/换浏览器，渠道页张数与内容 = 服务端返回值。
2. **新用户三预置渠道**：新账号首次进渠道页恰 3 张卡（聚鑫/SDGF/Ollama Cloud），key 空、标「未填 Key」。
3. **账号隔离**：A 自配 N 条、B 自配 M 条，各登各显示，零重复、零复活；用户删掉的渠道不得被任何机制复活。
4. **单机版不回归**：`standalone-v1.2.0` 行为零改动；缝合层只从**多用户登录路径**移除。
5. **生产位零扰动**：不动 `:3001` / `:3000` / `:8779`；不动 `.env` 与主密钥注入；S1 测试期间只动 `:8780`。
6. **凭据零明文**：文档/日志/命令行/提交历史零明文 key 与口令，一律 `[REDACTED]`；用户 key 只加密落盘。
7. **必停点**：push / tag / 合并主线 / 生产切换 / 生成类付费动作 / 对外交付——未经所有者拍板不得执行。
8. **交付形态**：只交所有者能用「自己眼睛+自己操作」检查的成品（打开 `:8780` → 登录 → 看渠道页）；工程探针页/裸 JSON 不算交付。
9. **禁发散**：只处理确认的问题，不顺手加功能、不加提示文案、不扩范围。
10. **验证零兜底**：FAIL 如实记，禁降级/均分/补成功；未跑项写「未跑」。
