# 镜头语言契约（单一事实源）

> 拆解与提示词改写共用这套镜头语言。拆解侧注入任务书（prompts/视频拆解.md 围栏正文 `{{镜头语言契约}}` 占位，extract.py 发送前替换）；提示词侧注入画布改写契约（web/src/lib/canvas/lapian-prompt-templates.ts raw import 本文件）。改这份文件即两侧同时生效，不许在任何一侧另抄一份。

## §1 选词表

镜头运动 / 机位与运镜的表述从下表选词，可加方向或速度修饰（如 匀速推近 / 快速右摇 / 缓慢升起），表内确实没有才用自由短语：

- 基础族：推、拉、摇、移、跟、升、降、环绕、甩镜、变焦、旋转、固定机位
- 复合与方向：推近、推进、前推、拉远、后拉、上摇、下摇、横摇、左摇、右摇、横移、左移、右移、跟拍、跟摇、跟随、升起、上升、下降、后退、前进、贴近、远离、俯冲、抬升
- 机位状态：手持、稳定器、仰拍、仰角、俯拍、俯角、平视、低机位、低角度、高机位、高角度、鸟瞰

升格 / 慢动作属时间节奏，特写 / 近景 / 中景 / 全景 / 远景属景别，都不入镜头运动表述。

## §2 镜头感受与灯光表述

镜头给人的感受直接写出来：「电影感」「很震撼」「极具冲击力」「松弛」「高级感」这类氛围词，连同灯光质感（顺光通透、硬影对比、暖调光泽），能准确传递这个镜头给人的感觉，视频模型靠它们理解要什么调性。落点：

- 拆解侧：写在「六 意境」层与分镜表的情绪 / 表演列——这是画面推导出的观感，不与可见事实混写。
- 提示词侧：写进它修饰的那个镜头句。

## §3 口吻

陈述句、现在时、动词驱动；只写看得见的东西与画面直接传递的感受，看不见的不猜。
