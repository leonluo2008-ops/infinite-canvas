## 「这个方式」的正式定义（可写入适配包正文）

画布自动化工作流承接层标准作业方式 = 六要素：

1. **契约前置**：agent 侧指令文件（agent-instructions.md）明确路由（拆解必须走 workflow 工具族，禁止 canvas_generate_video 冒充）、终点语义（停待批即报等审批，付费红线不自动续跑）。
2. **真跑链路**：拉片必须是真实 upload→run→job 轮询，禁止 text 节点模拟；失败在拉片链阶段则整单回滚、零节点落地（这是设计行为，不是丢节点）。
3. **资产指代显式**：用户说「用 @某图 替换」时必须传 `assetBindings`；实例已落地而槽未绑的补绑路径 = `canvas_update_node` 写资产位节点 `metadata.attachedImageId`（扁平唯一真源）。
4. **人工闸**：待审批是产品语义的一部分，不是流程缺陷；审批后才触发付费批量生成。
5. **双实例卫生**：画布 Agent 必须是仓库开发版（tsx），npx 发布版禁用（旧契约 + 端口竞争源）；统一入口 = 双击 `启动开发.bat`（幂等复用）。
6. **验证闭环**：每条契约改动都要在真实画布上读回验证；探针用 `--isolated` 或独立小任务，只删自建产物。
