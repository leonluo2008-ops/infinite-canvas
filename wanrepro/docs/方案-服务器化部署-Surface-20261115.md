## 一、目标

把 wanrepro 画布工具（web 前端 + bridge）部署为服务器形态：换机「装依赖→填 .env→一条命令起服务」≤30 分钟出可用入口；使用端浏览器零安装零密钥访问；使用端硬件零要求。

## 六、红线（逐条继承交接书 §6）

2. 文档/日志零明文密钥；.env 执行会话亲自迁移。
3. SYNC-GUIDE 类禁硬编码绝对路径；报告用文档发、只留唯一最新并清中间产物。
4. 验证零兜底：FAIL 如实记，禁降级静默容忍。

### B2 ✅
- web/ 是 **pnpm 工程**（npm ci peer 冲突失败是预期）→ `corepack enable pnpm`（装到 `~/.local/bin`）+ `pnpm install --frozen-lockfile`；`pnpm-workspace.yaml` 的 `allowBuilds.esbuild: true` 必须打开（esbuild postinstall 装平台二进制，否则 vite 起不来）。
- build 产物 ~4MB（gzip 1.27MB）24.4s。
- 实测方式：手工 preview 冒烟（本机真验 3001 页面+代理 200）后转 systemd；**手工测试进程残留占 :3001 会让 unit 起不来（Port in use）**，实踩已清。

### B3 ✅
- systemd 系统级双 unit（均 enabled）：
  - `wanrepro-bridge.service`：`EnvironmentFile=/home/luo/wanrepro-server/wanrepro/.env`（P0-1 落实），`/proc/<pid>/environ` 验证密钥已注入（只验存在不回显值）。
  - `wanrepro-web.service`：`node node_modules/vite/bin/vite.js preview --host 0.0.0.0 --port 3001 --strictPort`，`After=`+`Requires=` bridge。
- Restart=on-failure 故障恢复实测通过。注意：**preview 不拉 bridge**（autoStartBridge 仅 dev 生效），bridge 100% 靠 systemd 管控。
