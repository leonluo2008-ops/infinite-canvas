## 拉片链动态点验（写进交付说明的静态+请求级证据）

→ `getMediaBlob` 取 Blob（取不回即报错，不发请求）
→ `POST /api/video/upload`，头 `X-Filename: encodeURIComponent(title)` + `Content-Type: application/octet-stream`，body = Blob → `{id}`
→ `POST /api/lapian/run`，body `buildLapianRunBody(id, intent, effectiveModel, channels)`（未配模型时**只** `{id,intent}`）→ `{job}`

`executeLapianChain({storageKey,title,intent,config},{getBlob,fetch,log})` 后只保留「落节点/连线/视口」；
`LOG("getting blob")` / `LOG("blob=…")` / `LOG("upload=…")` / `LOG("run=…")` 与全部错误文案由公共实现原样产出
（`视频字节取不回（…）——重新拖入视频`、`这个视频节点没有本地字节（…）`）。

## 关键语义（后续 P4/P5 依赖）

- **确定性 id 即幂等锚**：`templateInstanceNodeId(templateId, instanceIndex, oldId)` / `...ConnectionId(...)`；同素材同序号重放 → 同批 id → 落库时全部幂等跳过。
- **add_node 幂等键的「形态」口径**：`type + metadata`（键排序稳定序列化），**不含** `position/title/width/height`——用户挪动/改标题后重放仍算同一节点；`metadata` 变化才判冲突。
- **失败三档**：① 计划期（素材缺失/模板不自足/槽违规）→ 抛错，零写入零网络；② 槽①执行期（取字节/上传/发起/正文）→ 不提交任何 ops，`status:"incomplete"` + `stage:"lapian_chain"|"lapian_content"`；③ 落库期 → 下发 `buildInstanceRollbackOps`（只删本实例节点/连线），`rolledBack:true`。
- **`incomplete` 不等于完整实例**：`lapian_content` 档会落节点（带本次 `taskId/jobId`、正文空），调用方必须读 `status/incomplete.stage` 决定是续查还是重做。
- **派生资产位不发明**：模板槽③为 `derived` 时挂图直接拒绝（`asset_slot_derivation_required`），等 P4 派生出槽再挂。

## 付费归属（P0b 闸口径）

槽①拉片属**前置自动段**（上传 + 拆解），产生的是 bridge 侧拆解费用，**不是**视频生成付费创建；本卡提交的 ops 内
`run_generation` 条数恒为 0（探针断言），故不触发 P0b 付费闸。真跑探针全程 stub 拦截 `/api/video/upload`、`/api/lapian/run`、
`/api/job/*`、`/api/lapian/*`，**零真实调用零真实扣费**。
