### 四、 异常现象与报错清单

1. **模态框反复强制弹出阻断操作（高频循环弹出 Bug）**
   * **时间点**：00:18、00:35、00:52（共 3 次）。
   * **现象**：用户配置好代理并手动关闭弹窗后，在毫无操作或仅查看画布状态下，系统反复无故弹窗【配置服务与插件】。即使 00:58 已经显示“本地代理连接成功”，弹窗依然持续闪烁并弹出，破坏了操作连贯性。

2. **MCP 参数类型校验报错（逐字报错文案）**
   * **时间点**：00:34 - 00:50 持续显示在右侧 Agent 面板。
   * **逐字报错信息**：
     * `执行任务 失败: 执行规划工件失败: MCP 调用的参数必须是一个纯对象: <nil>。例如参数为 solxRun 时，参数应该是一个纯对象类似 {'solxRun': 123}`
     * `创建产品宣传视频工作区节点 失败`
     * `生成宣传视频 失败`
   * **原因分析**：Agent 在调用底层 MCP（Model Context Protocol）插件工具时，传入了 `<nil>`（空指针/未定义参数），导致类型校验直接抛异常熔断，使得后续工作流创建失败。

3. **Codex 对话框卡在未初始化状态**
   * **提示文案**：`允许初始化对话，Codex 才能正常处理。`
   * **现象**：下方聊天输入区域虽然有快捷指令提示（如 `Shift+Enter，换行；输入 / 获取节点引用`），但在任务报错和缺少明确初始化授权确认流的情况下，对话框交互处于被挂起/阻塞态，未能正常承接与用户的多轮对话。
