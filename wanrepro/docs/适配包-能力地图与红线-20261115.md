## 二、画布拆解工作流（核心成果，零回归面）

- 内置模板 `builtin-video-analysis`「视频拆解（内置）」：`run_workflow_batch` / `run_workflow_instance` / `extract_workflow_template`（canvas-agent schemas + MCP 全量 38 工具）。
- 真拉片链：upload → `/api/lapian/run` → job 轮询 → 拆解产物门禁（D1–D8，不合格自动重拆）。**禁止 text 节点模拟拉片、禁止 canvas_generate_video 冒充拆解**（契约 a-f，canvas-agent/agent-instructions.md）。
- 实例结构：模板节点 id 按 `templateInstanceNodeId(templateId, instanceIndex, 原id)` 派生；资产位=官方 image 节点（`assetSlotSourceId/assetSlotOrder/assetSlotName`）。
- **资产绑定唯一真源**：资产位节点 `metadata.attachedImageId`（扁平字段；assetSlot.attachedImageId 仅审计镜像）。补绑=`canvas_update_node` 写该字段。
- 终点=**待审批**（P0b 人工闸）：审批后批量生成；Agent 提交=对实例生成配置节点 `run_generation`（通用通道，真机已验证），**仅凭所有者显式指令，禁自主批量提交；有实例组装链必须用实例的**（不得绕过拉片组装自建提示词）。
- 失败语义：lapian_chain 阶段失败→整单回滚、零节点落地（设计行为）。

## 三、生成管线固化点（web/src/services/api/video.ts）

- **音频恒开**：5 处 `boolConfig(config.videoGenerateAudio,…)` 已全部改常量 `true`（owner 拍板：无声选项不存在）。创作台开关/配置节点徽标/agent generateAudio 参数已全撤；store 字段仅旧数据兼容。
- **按模型族声音参数派发**（`sdgfSoundFields`，sdgf-payload.ts）：满血 GF=顶层 `enableSound:"on"`；ap 系=`metadata.enableSound:"on"`（顶层会被站方静默忽略）。探针钉住，勿动。
- 出片等待：`onPhase("downloading")` → 节点 `videoPhase`「生成完成，下载中…」+ F3 提前探测（pending≥90 连续 5 次提前拉成片）。
- 成片自动下载落节点（poll→blob→节点内容）——画布即验收面，无独立下载方案。
