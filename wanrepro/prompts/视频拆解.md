# 视频拆解 · 提取提示词

## 两条铁律（实测得来，不是经验之谈）

> **铁律一 · 只问「看到什么」，不问「这是什么」。**
> 模型能可靠回答：形状、颜色、位置、尺寸、运动轨迹、速度、光影、文字。
> 模型**不可靠**回答：道具/材质名字、品牌身份与商业含义、人物身份、拍摄意图。
> 注意区分：问「这是什么牌子、品牌什么档次」→ 它编；照抄「画面上印着哪些字、什么颜色、在哪里」→ 它可靠（第十层就建立在这个可靠能力上）。
> 问「遮挡物是什么」→ 它编「木制折叠尺」（实测 2/2 次都编）。问「轨迹是圆弧还是直线、圆心在哪」→ 它照实答。

> **铁律二 · 不让模型决定结构。**
> 输出 JSON 时，同一变体两次跑出的键名都不一样（实测 6 个变体无一例外，每层 3–6 种键名组合）。
> 改成**固定 Markdown 标题**后，6/6 次全部九个标题齐全、顺序正确、零多余标题。

## 提示词正文（原样使用）

```
你是广告片导演。按下面十个标题逐节回答。

【铁律一】下面十个标题必须原样出现、顺序不变、一个不许少、不许合并、不许自己加新标题。
【铁律二】不要猜道具或材质的名字（不要写木尺、木臂、金属杆之类）。看不清就写「不明」，
改为描述形状、颜色、尺寸、位置、运动轨迹的几何特征。
【铁律三】既写手段，也写它给人的感受：材质、光位、反光、背景要写实，让人看见画面；「高级感」「氛围感」这类词可以出现，它们能有效引导模型，和具体手段一起写效果最好。
【铁律四】画面里出现**完整或主要人物**时，必须写明**看得见的人种外观**：欧美 / 亚洲 / 非洲 / 拉丁 / 中东 / 混血。只有局部肢体（手/背影/剪影）的不写人种——那不是人物条目，是道具。
（实在看不出写「人种不明」）、年龄段、性别、肤色深浅、发型发色、体型。这是外形特征不是身份推断，
一个字都不许省——漏了它，下游生成的片子会换成另一国人。
【铁律五】让人看得见：只写你确实看见的东西，并且写到别人能照着把它拍出来。
【铁律六】画面里印着的字是事实，照抄：把看得见的文字内容原样抄下来（含大小写、标点、感叹号），
再写它的字体形态、颜色、位置、出现时段、动效。读不清的字写「部分可辨：<能读出的部分>」，不许脑补成完整词。
这一层永远不回答「这是什么牌子」——只登记画面上看得见的字。
- 手或物体从画面边缘进来：写清从哪一侧、什么姿态、先碰到什么。
- 从屏幕、镜子、水面里钻出来：写清穿过的是哪块面、从哪个位置穿出、穿出后往哪走，并把该镜转场方式标 `穿屏`。
- 被挡住、只露一角、已经出画：写你实际看到的边界（例如「只露出指节」「被瓶身挡住半边」），没看见的部分就停在边界上，不要替它补一个合理的样子。

## 一 场景
在哪、什么材质、色调、背景里有什么、有没有固定的光斑或阴影形状

## 二 产品
几个产品、各长什么样、什么时候换成下一个。**有几个产品就分几条写**，一条一个产品，写成
`**媒介产品（00:01-00:05）**：…` / `**核心产品（00:04-00:14）**：…` 这种格式，
不许把两个产品塞进一条——塞进一条后面就只剩第一个能被登记成资产。

## 三 运动
运动主体是谁；轨迹是圆弧扫过还是直线平移；如果是圆弧，圆心在哪、什么方向；
是否周期性重复、间隔是否相等；速度曲线；入画出画方向；有没有运动模糊、模糊在哪个物体上

## 四 光影
光源方向与软硬；有没有动态阴影（谁投的、形状、怎么移动）；阴影与实体谁先入画；
整体亮度是否随运动变化

## 五 镜头
写成两行，行首写 `- `，冒号前写行名（下游按行名取运镜）：
- **机位与运镜**：机位角度；镜头本身有没有动（含微小震动）；多镜就按秒逐段写
【选词·镜头语言】遵循上文分镜表部分的【镜头语言契约】同一份选词与感受表述。
- **焦段与景深**：景别变化；焦段的感觉（广角 / 标准 / 长焦 / 微距）；景深哪里清晰哪里虚化、焦点有无转移

## 六 意境
整体调性一句话；**情绪基调**：全片什么情绪（如 轻快 / 治愈 / 松弛 / 自信 / 俏皮 / 紧张 / 压抑 / 神秘），有没有从一种转到另一种；靠什么手法做出这个感觉（列具体手段）；节奏感：快慢对比在哪、重音落在哪一帧

## 七 分镜表
先答一镜到底，再写首帧，各自单独一行（用 `- ` 开头，不要写成标题）：
- 一镜到底：是 / 否（镜头中间有没有剪辑点）
- 首帧：把 0 秒那一帧写成**一句能看见画面的话**——人在画面的哪个位置、身体怎么站（正对／侧对／背对镜头）、头怎么转、眼睛落在哪、手上在做什么、周围是什么光景；有「看帧判定」就照它同秒那一句落笔（没有人物写「无人物」）
- `首帧` 行与分镜表的 `站位`/`朝向`/`视线` 三列，照「看帧判定」里同秒那一帧的写法落笔；判定里没写的，再按你看到的补。
一段一行，写成：镜号 | 起秒-止秒 | 运动主体 | 运动形态 | 速度 | 画面内容 | 光影变化 | 转场方式 | 站位 | 朝向 | 视线 | 镜头运动 | 景别 | 情绪/表演

`情绪/表演` 这一列写成「情绪词 + 看得见的表演」：

- 先给 2–4 字的情绪词（松弛展示 / 短暂惊讶 / 得意 / 警惕 / 好奇 / 专注…），后面跟支撑它的可见信号：眉毛、眼睛、嘴、下颌、呼吸、肩颈、手势；
- 看不见脸（背对 / 远景 / 无人物）写「无可见表情（背对/远景）」，不替它补一个表情；
- 情绪可以在镜内变化，写成「先…后…」；
- 因果按画面发生的顺序写：先写发生了什么（浪打飞瓶），再写她的反应（抬眼、眉毛抬起、嘴张成小口）。

后 5 列逐镜都要填，一列都不许空（空一列等于这一镜没法按你的描述复现）：
- 站位：人物在画面中的位置（左/中/右、前/中/后景、占画面多大），没有人物就写「无人物」
- 朝向：身体朝向相对镜头（正对/侧身/背对 + 左/右），没有人物写「—」
- 视线：看向哪里（镜头 / 道具名 / 画外），没有写「—」
- 镜头运动：这一镜机器怎么动——怎么选词看紧跟着的这段
{{镜头语言契约}}
- 景别：远景 / 全景 / 中景 / 近景 / 特写 / 极特写

转场方式只许四选一：无剪切 / 穿屏 / 遮挡 / 剪辑。写「跳切」「匹配穿透」「渐变过渡」这类词算不合格。

**整表必须从 00:00 连续覆盖到片尾最后一帧**：最后一镜的止秒写到你看见的画面结束那一刻，片尾定格 / 尾卡 / 品牌字定格单独成一镜（不要只写在第十层，也不要漏在表外）。片长 6 秒的片子，末镜长这样（正例，14 列一列不少）：

    05 | 00:05-00:06 | 品牌字与产品 | 静止 | 定格 | 纯色背景中央上方白色品牌字，下方产品静置悬浮，画面不动不切 | 均匀柔光，无变化 | 剪辑 | 正中 | — | — | 固定机位 | 全景 | 无可见表情（无人物）

止秒要跟片尾画面对齐：整表最后一镜若不是片尾定格，或末镜止秒比片尾短（片长 6.04 秒却只写到 00:05），下游会把整张表判成不可解析——上面每一镜都用不上（pop-1 事故现场：4 镜全废、代表帧全落兜底）。拿不准片长时，从 00:00 起按你实际看到的每段时长逐镜累加，最后一镜收在画面结束。

## 八 声音
有没有人说话、什么语种、逐句台词；有没有 BGM、什么乐器；音效或节拍与画面动作怎么对应

## 九 资产
要复现这个创意需要准备哪几张图/什么道具，每样写清「必须锁住什么」。

**必须逐条列，一条一个资产，格式：`* **资产名（出现于：镜 N-M）**：可见外形描述`**

- **先数一遍画面，再决定登记什么——画面里实际出镜的才登记，没看见的不硬造**。人物/服装/动物先判断有没有，三种写法：
  - **全片没有任何人出现**（包括只露手/脚的片型）→ 人物栏只写一行：`人物：无（全片无人物出镜）`；服装栏写 `服装：无`。
  - **只看见零星部位**（入画的手、脚、单段肢体；看不到这是一个「出镜的人」）→ 人物栏写 `人物：无完整人物（仅<部位>入画，<部位>外形写在道具里）`，再把该部位作为一条**道具**登记（写清肤色/部位/画面里到哪一截，如「只到手腕」；随部位入画的袖口/表带等小件一并写在这条里）；服装栏写 `服装：无`。
  - **画面里有出镜的人**——脸和上半身可见的口播/近景、远景里看得出是人形的、背对镜头或剪影轮廓完整的、半身/局部但明显是「一个角色」的——都登记人物条目（按下面规则），**看不见的部分如实写「不可见」**（如「背影，正脸不可见」），不脑补。
  - **人物条目是给「要配图、要锁形象」的角色准备的**：这部片子换掉谁创意就不成立，谁才是主体，才登记人物条目和配套服装条目。背景里一闪而过、不参与叙事、换成任何路人都不影响创意的路人，属于场景氛围——在场景条目里带一笔（如「背景有行人/车辆经过」）即可，不单独立人物/服装条目。判断口诀：**镜头给过他独立画面 / 他与产品有互动 / 他在多个镜头里持续出现**——三条占一条就是主体，一条都不占就是背景。
  - 动物同规则：出镜的动物登记 `动物A`（品种/毛色/体型，看不见的写不可见）；没有动物就不用写这一类。
- **与看帧判定对齐时按同一时刻对**：看帧判定覆盖的那一秒/窗口里写「无人物」的，同一时刻的人物登记保持一致；看帧没覆盖的时段（如后段才入画的人）照你在全片里看到的登记。两处对不上时，把「哪个时段、看到了什么」写清楚，留给人工核对。
- **分四类写，类型写在名字开头**：`人物` / `服装` / `道具` / `场景`（动物条目并进人物类段，名字以 `动物` 开头）。
- **同一个人换衣服 = 多个服装资产**：写 `服装A`、`服装B`…，各自描述那一套（颜色/版型/领口袖长/鞋/配饰）。
  **`人物` 那条只写脸和身形，不许把衣服写进去**——服装是独立资产，后面要单独配图。
- **每条都要有「出现于」，且两段一起给**：先写秒数段、再写镜号，格式固定为
  `出现于：HH:MM-HH:MM / 镜N-M`（秒数照抄分镜表里那几镜的起止秒；同一件东西出现在不连续的地方就都写上，
  例 `出现于：00:01-00:05 / 镜1-3、00:09-00:11 / 镜7`）。分镜表读不出才退回只写镜号（`出现于：镜 1、7`）；
  两段都给的理由：下游先认秒数、再认镜号，只给镜号的条目在表被判不可解析时会整条丢时段。
  实在判断不出来写 `出现于：未标注`，不许省略这一段。（「无」的说明行不需要出现于。
  整条片都在、镜次又说不清时可直接写 `出现于：全片`，这是唯一允许的单段写法。）
- **每行完整写法正例（一条资产一行，`出现于` 与 `画面位置` 两段都落在这一行里，照抄结构、内容按你看到的填）**：

    * **服装A（出现于：00:01-00:05 / 镜1-3）**：黑色工字背心 + 黑色骑行短裤 + 白色运动鞋，画面位置：九宫格5·镜2
    * **道具A（出现于：00:02-00:04 / 镜2-3）**：手持的扁平长方形设备，深灰中框、背面三摄，画面位置：九宫格6·镜3
- 【§9·画面位置】每条资产条目末尾再固定追加一段 `画面位置：九宫格N·镜M`（这是条目的一部分，
  不是新标题、不单起一行标题）：把画面当 3×3 九宫格，从左到右、从上到下编号 1–9
  （1=左上、2=中上、3=右上、4=左中、5=正中、6=右中、7=左下、8=中下、9=右下），
  N 写这个资产在画面里最典型落在哪个格（跨多格写它停留最久/最主要的那一格）；
  M 写分镜表里它最典型的那个镜号。写法示例：`画面位置：九宫格5·镜2`。
  每条资产都要带这一段；「人物：无」这类说明行不用带。
- 场景有几个写几个（同一支片里换场景很常见，第二个场景别丢）。
- 道具写清是干什么用的（手持/抛出/遮挡/机关）。

样例一（有人物片，照这个结构写，内容按你看到的填）：

    * **人物（出现于：00:00-00:05 / 镜 1、4、7）**：20-25 岁女性，脸型、肤色、发型、身高体型，画面位置：九宫格5·镜1
    * **服装A（出现于：00:00-00:05 / 镜 1、7）**：黑色工字背心 + 黑色骑行短裤 + 白色运动鞋，画面位置：九宫格5·镜1
    * **服装B（出现于：00:02-00:04 / 镜 4、5）**：铁锈橙方领无袖连衣裙 + 浅色一字带高跟凉鞋，画面位置：九宫格4·镜4
    * **道具A（出现于：00:01-00:02 / 镜 2-3）**：手持的扁平长方形设备，深灰中框、背面三摄，画面位置：九宫格6·镜2
    * **场景A（出现于：00:00-00:02 / 镜 1-3）**：暖黄地铁车厢，橙色长条座椅，顶部两排长灯，画面位置：九宫格8·镜1
    * **场景B（出现于：00:02-00:05 / 镜 4-7）**：纯白几何空间，冷白发光灯带，画面位置：九宫格5·镜4

样例二（**无人物片**——全片只有产品、陪衬物与入画的手，人物栏照实写「无完整人物」）：

    * 人物：无完整人物（仅手部入画，手的外形写在道具B里）
    * 服装：无
    * **道具A（出现于：00:00-00:03 / 镜 1-3）**：俯视台面中央陈列的主产品，外形照实写（形状/颜色/材质/文字区域），画面位置：九宫格5·镜1

## 十 图文与收束

这一层登记画面里**看得见的文字与图形标识**，以及结尾怎么收束。它在九层之外单独一层，因为
文字元素不属于任何实体资产（水印不是道具），收束是时间轴结构（资产层没有时间语义）。

**图文元素**——全片任何时段出现的持久性文字/标识，逐条登记：
- 每条格式：`* **元素名（出现于：时段）**：「文字内容」照抄｜字体形态（衬线/无衬线、粗细、字高与画面的相对大小）｜颜色｜位置（画面哪里）｜动效（淡入/弹出/放大定格/无）`
- 品牌字、标语、字幕、角标、水印、包装上的字，画面里看得见就算一条。
- **只照抄画面可见文字**，不判断这是什么牌子、不写品牌含义来历（铁律六）。
- 读不清写「部分可辨：<能读出的部分>」。
- 全片没有任何可见文字时，写一行 `图文：无（全片画面无持久性文字元素）`。

**尾段收束**——片尾怎么收的（通常最后 1-2 秒）：
- 收束类型五选一：`品牌字定格板` / `产品与品牌字同框` / `字幕标语收束` / `无品牌露出` / `其他`（照实写）。
- 版式：各元素位置关系（谁居中、谁在上、谁压着谁、背景是什么）。
- 动效时序：谁先出现、大约几秒、怎么动（淡入/弹出/翻转定格）。
- 没有收束设计（片子直接结束）就写 `收束：无品牌露出，画面直接结束`。

样例一（有品牌收束片）：

    * **品牌字（出现于：00:04-00:05）**：「SPARK!」白色无衬线粗体大字，顶部居中，半透明压暗；淡入
    * **包装字（出现于：00:00-00:05）**：「GLOW WATER」白色加粗大写，瓶身右侧纵向；部分可辨：「EAU DE …」
    * **收束**：类型=产品与品牌字同框；版式=产品垂直居中悬浮、品牌字顶部居中、背景为虚化街景实拍；动效时序=产品翻转减速先定格（约 0.5 秒），品牌字随后淡入（约 0.3 秒）

样例二（无品牌露出片）：

    * 图文：无（全片画面无持久性文字元素）
    * **收束**：类型=无品牌露出；片尾（00:05-00:06）产品静置于台面中央，画面渐暗收束

## 赛马实测记录（2026-10-29）

夹具：A 遮挡换款片 15.04s（有机关）· B 真人口播片 10.05s（有台词有手持）· C 静物平铺片 13.35s（无机关）

| 变体 | JSON 可解析 | A 片瞎编道具 | A 片几何词 | A 片段数（真值4） | 耗时 |
|---|---|---|---|---|---|
| V1 九层无禁令 | 100% | **2.0（两轮都编）** | 4.5 | 4.0 ✓ | 43s |
| **V2 九层+禁令** | 83%（1 条 API 空响应） | **0.0** | **7.0（最高）** | **4.0 ✓** | **38s（最快）** |
| V3 两次调用 | 100% | 0.0 | 5.5 | 4.5 ✗ | 68s（最慢） |
| V4 先自由描述 | 100% | 0.0 | 4.0 | 5.5 ✗ 过度切分 | 46s |
| V5 禁令+自检 | 100% | 0.0 | 4.0 | 4.0 ✓ | 39s |
| V6 七层精简 | 100% | 0.0 | 5.0 | 4.0 ✓ | 43s |

**结论**

1. **禁令必须上**。V1 是唯一会瞎编道具的，且两轮都编。V2–V6 加了禁令后全部归零。
2. **自检没用**（V5 相对 V2 无增益）。**两次调用最贵且无增益**（V3 68s）。**先自由描述反而导致过度切分**（V4 切出 5.5 段，真值 4）。
3. **七层精简可行**（V6 无损失且更快），但保留九层更利于写提示词（场景与产品是渲染必需的），维持九层。
4. **JSON 键名完全不可靠**——所有变体每层都有 3–6 种键名组合。**必须改固定 Markdown 标题**（验证 6/6 全稳）。

## 接口纪律（踩过的坑）

| 坑 | 现象 | 处置 |
|---|---|---|
| 走代理 | `ssl.SSLEOFError: EOF occurred in violation of protocol`；或 HTTP 200 但 `candidates` 为空、正文长度 0 | **聚鑫海外站直连，不走代理**。urllib 要用 `ProxyHandler({})` 或清空 `HTTP(S)_PROXY` |
| 空响应不报错 | `finishReason=None`、`text=""`，被当成功存下来 | 必须判空并重试，不能把空文本当结果 |
| 静默下线 | 旧模型返回 HTTP 200，正文是下线通知 | 校验正文是否含下线关键词 |

## 下游怎么消费（渲染器不要碰 JSON 键名）

渲染器按 **标题** 切段，不按字段名取：

```python
SECTIONS = ["一 场景","二 产品","三 运动","四 光影","五 镜头","六 意境","七 分镜表","八 声音","九 资产"]
# 用 ^##\s*(标题) 切分，取每段正文
# 七段提示词模板消费的是「段正文」，不是字段
```

缺标题 → 显式报错（说明这一层模型没答），**不许用空字符串兜底**。
