# wan-repro 整合包 · 部署指南（v1.0.0）

> 面向**部署到客户 Windows 电脑**的操作手册。整合包 = 单文件夹自包含（运行时+程序+文档），拷过去就能跑，不装任何环境。

## 一、你需要提供什么

| 项 | 用在哪 | 不提供会怎样 | 怎么准备 |
|---|---|---|---|
| **渠道 API Key**（聚鑫等） | 拉片拆解、视频生成的模型调用 | 画布能打开，但「拉片」「生成视频」报无渠道 | 部署前填进 `app/config/channel-config.json`（模板见同目录 `channel-config.example.json`），或部署后画布里手动配置（配置面板→渠道） |
| **渠道「多模态」标签** | 拉片节点的「分析模型」下拉列表 | 拉片时选不到分析模型（下拉为空，走默认模型） | 画布配置面板→渠道→编辑→模型行能力标签勾选「**多模态·图像/视频识别**」（理解型多模态：读图/读视频，与「生图」出图不同）；勾选后拉片弹层即可按渠道分组选模型 |
| **Hermes Agent**（可选但推荐） | 画布内 AI 对话助手节点 | 画布其他功能全部可用，仅 Agent 对话不可用 | 客户机另装 Hermes（见下文第四节），整合包不含也不需要 |
| 参考视频素材 | 拉片拆解的输入 | 无——用户上传自己的视频即可 | 无需准备 |

**口令**：首次启动自动生成随机口令（`config/token`），菜单 [5] 可改。本机打开画布免口令；口令链接用于同网其他人或公网隧道场景。

## 二、部署步骤（在客户电脑上）

1. 把整个 `wan-repro-bundle` 文件夹拷到客户电脑任意盘（**路径含中文/空格都可以**，脚本从自身位置推导）。
2. 双击 `启动整合包.bat` → 按 `1` 启动服务 → 显示 `http://127.0.0.1:8776` 即就绪。
3. 按 `6` 打开画布（或浏览器手动访问上面地址）。
4. 首次打开若 `config/channel-config.json` 已配好，渠道自动导入；否则在画布「配置」面板手动添加渠道（**API 格式按渠道说明选，SDGF 类视频渠道必须选 `sdgf`**，选错会报 `requires public media URLs`）。
5. 试跑一条链：上传参考视频 → 拉片 → 衍生资产位 → 挂图 → 生成视频提示词 → 生成视频。

## 三、不需要做的事

- ❌ **不需要安装 Python / Node / ffmpeg**——运行时全部在 `runtime/` 里。
- ❌ **不需要配环境变量 / 改系统 PATH**。
- ❌ **不需要管理员权限**（单用户进程，注册表零写入）。
- ❌ **不需要联网下载任何东西**（离线可用；只有拉片/生成时访问模型 API 需要出网，直连即可）。
- ❌ **不需要公网 IP / 域名**（本机使用；要给外部演示时用 Cloudflare 隧道，另见 `docs/公网演示.md`）。

## 四、Hermes Agent 部署与连接（可选）

画布的 AI 对话助手节点走本地 Hermes Agent 服务，整合包**不含** Hermes 本体（体积与授权原因）。客户机需要时：

1. 在客户机安装 Hermes（安装包另行提供）。
2. 启动画布 Agent 服务（默认端口 `17371`）。
3. 画布里配置连接：Agent 节点/设置 → 连接地址填 `http://127.0.0.1:17371`。
4. 连接成功后画布内即可对话、多模态引用（图/视频/音频节点拖进对话）。

## 五、故障排查

| 症状 | 最可能原因 | 怎么办 |
|---|---|---|
| 启动报「缺少运行时」 | 包不完整（拷贝中断） | 重新拷贝整个文件夹 |
| 端口 15 秒未就绪 | 8776 被占用 | 菜单 [7] 看日志；或改 `启动整合包.bat` 里 `PORT=` 换端口 |
| 画布打不开（浏览器转圈） | 服务没起 / 端口不对 | 菜单 [4] 看状态，重启 [3] |
| 拉片报「无渠道」 | 没配渠道 | 画布配置面板添加，或填 `channel-config.json` 后**清浏览器站点数据**重开（首启导入只跑一次） |
| 生成视频报 `requires public media URLs` | 渠道 API 格式选成 openai | 改成 `sdgf` |
| 生成视频报图床错误 | 客户机出网异常 | 检查防火墙/代理，uguu.se 需可达 |
| Agent 对话无响应 | Hermes 未启动/地址错 | 见第四节 |

## 六、目录说明

```
wan-repro-bundle\
  启动整合包.bat        ← 双击这个（管理菜单）
  app\                  程序（画布静态产物 + bridge + 拆解链）
  config\               口令与渠道预置（channel-config.json 部署时填）
  runtime\              Python + ffmpeg（自包含，勿动）
  work\                 用户数据（上传的视频/拉片产物都在这）
  logs\                 运行日志
  docs\                 本文档 + 组件许可证
```

**数据都在 `work\`**——迁移/备份拷这个目录即可。删掉 `work\` = 恢复出厂（画布节点数据在浏览器 IndexedDB 里，清浏览器站点数据即清空）。
