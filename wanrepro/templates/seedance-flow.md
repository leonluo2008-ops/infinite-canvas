# 模板 E · 单段流式（Seedance 系）

## 出处与可信度（先看这段）

- **唯一依据**：`docs/原提示词-单段流式.md` —— 逐字抄录自 `人工目录-AI勿删/即梦画布/视频生成提示词.txt`，
  甲方那条片子真正拿去出片的提示词。不是归纳、不是拟制。
- **照它抄的三件事**：
  ① 开头一句给全局：画幅 + 影像质感 + 主体图号指认（`全程使用参考图中的 @图片N 说明`）；
  ② 中段按 `N-M秒` 连续推进，一个时段一句，句内把景别 / 主体 / 动作 / 镜头 / 画面 / 转场一次说完，
  句与句直接相接、不换行、不空行，整片是一段话；
  ③ 末尾一句全片一致性约束（运镜平滑、转场自然、色调过渡、人物与产品不变形）。
- **不抄的**：`#`/`##` 标题、附注、字段名回显、参数位（`--ar` / seed / 负面词表）—— 原件里 0 处。
  正文就是一段可以直接贴进生成平台的文字，贴进去即可用。
- **样本量 = 1 条**。所以本文件只说「这条片子这么写」，不写「N/N 条都这样」。

## 适用场景

- 单条 5–15 秒、**按时段节拍推进**的创意短片（变装、破屏、递物、产品阵列揭示）。
- 生成端只吃**连续叙事文本**、按时间码理解节拍（Seedance 系 / 即梦画布）。
- 需要一条提示词里把**主体指认 + 时段推进 + 全片约束**串成一段，不做分节排版。
- 不适用：需要四段式结构化（用模板 A）；需要甲方清单逐条勾对（用模板 B）；
  需要一句一条、便于逐条改的叙事底稿（用模板 D，它保留行结构）。

## 段落定义

### 第 1 段：全局设定与主体指认

- 写什么：一句开场——先给画幅与影像质感，再逐个指认主体：每个人物、产品、场景各给一个图号和一个 2–6 字短说明，一句到底。外形、颜色、材质、发型、服装一律不写，细节交给图。
- 数据来源：`九层 九（资产）` → 实体图号（编号来自待确认清单）
- 实体指认：是
- 口吻：陈述句、现在时；一句 40–80 字；不出现「请」「建议」「需要你」。
- 原文依据：docs/原提示词-单段流式.md §1

### 第 2 段：时段连续推进

- 写什么：每个时段一句，时间码开头（`N-M秒`）：先说景别与场景，再说清主体（图号紧跟）、动作与朝向，接镜头状态（每个时段句必带：运动方式+方向或速度；原片机位不动就写机位固定），最后是画面内容与转场；镜头给人的感受（如「电影感」「很震撼」「极具冲击力」）与灯光质感写在该时段句里，帮视频模型理解调性；句与句直接相接成一段，不换行、不空行。
- 数据来源：`九层 七（分镜表）` → 分镜逐镜取值
- 分镜列：时段,景别?,运动主体,运动形态,画面内容,转场方式?
- 时段格式：秒
- 连写：是
- 口吻：陈述句、现在时、动词驱动；句内只用「，」，不用分号与竖线。
- 原文依据：docs/原提示词-单段流式.md §2

### 第 3 段：全程一致性收尾

- 写什么：一句收尾约束——运镜平滑与转场自然、色调过渡连贯、人物形象与所引图一致、产品外观全程不变形；只写约束，不解释理由、不写参数。
- 数据来源：`九层 五（镜头）` → 运镜连续性
- 原句输出：全程运镜平滑流畅，转场自然，色调过渡连贯，人物形象与所引图一致，产品外观全程无变形。
- 口吻：陈述句；一句到底，句内只用「，」。
- 原文依据：docs/原提示词-单段流式.md §3

## 可选段

### 可选段 C：品牌收束与图文（第十层「图文与收束」）

- 写什么：正文末尾接一句收束——收束类型（品牌字定格板 / 产品与品牌字同框 / 字幕标语收束 / 无品牌露出 / 其他照实写）+ 版式（谁居中、谁在上、谁压着谁、背景是什么）+ 动效时序（谁先出现、大约几秒、怎么动），全片持久性文字/标识逐条带上。**品牌字位一律写「客户品牌字样」占位**——借创意不复刻品牌，参考片原字一个不写；参考图用 `@图片N` 指代并只带 2–6 字典型说明。全片没有持久性文字就写「图文：无」。
- 数据来源：`十层 十（图文与收束）` → 收束类型/版式/动效时序；图文元素逐条
- 字样置换：是
- 口吻：陈述句、现在时；一句到底，句内只用「，」，不用分号与竖线。
- 原文依据：docs/原提示词-单段流式.md §2（原件时段推进的末句就是收束句：「画面中央浮现黄色粗体文字P.OP!，下方小字PERFUME OF PEOPLE，最后画面逐渐暗下淡出至纯黑。」——品牌字位 + 版式 + 动效时序 + 淡出收尾，一处写全）
- 渲染建议：拆解有「十 图文与收束」层时开这一段（`--optional C`）；旧九层拆解没有这一层，保持关闭。

## 渲染器行为注记（改本文件前先读）

1. **`正文模式: 流式`**：渲染器只输出一段正文——无 `# 提示词` 标题、无 `**全片规格**`、无 `## 段标题`、无 `# 附注`，
   段与段之间直接相接。要文档形态时用 `--body-mode 文档` 覆盖（调试用）。
2. **`实体指认：是`**：该段只产出一句 `全程使用参考图中的 @图片N 说明、…`，**不消费拆解子块**；
   说明词优先取实体命名，没有命名退到类别词（产品 / 人物 / 场景 / 道具）。
   这一段不许再写外形描述——参考图规则：每个实体固定一个短说明，细节交给图。
3. **`分镜列` + `时段格式：秒` + `连写：是`**：段 2 把「七 分镜表」按声明列拼句子，
   行首时间码归一成 `N-M秒`，然后把各句**直接相接**成一段。列名带 `?` 的是可选列，旧拆解没有就跳过；
   不带 `?` 的列缺一列即 exit 3。
4. **`原句输出：…`**：段 3 原样输出这一句（出处见该段 `原文依据`）。句子是模板资产，不是模型自由发挥的段落。
5. `段 1 / 段 3` 都**不消费拆解子块**（自带句子），只有段 2 消费分镜表；把段 2 挪走，正文就只剩两句话。
