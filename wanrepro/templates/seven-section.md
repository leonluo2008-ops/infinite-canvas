# 模板 C · 七段（备选）

## 出处与可信度（先看这段，别跳过）

- **这份模板没有甲方成品依据。** 七个标题是我方早期自己拟的，不是从任何一条甲方产出的提示词里抄出来的。
- **精确指引**：`docs/调研/官方最佳实践对照审计.md` 只到「五段」——它体检的 C2（吊扇换款那条历史提示词）写的是「一、产品参考 二、场景构图光线 三、叶片运动 四、逐秒分镜 五、声音」。本模板的「0 总述」与「六 全程约束」两段，**连那份对照表里都没有**，是我方后加的。
- 同一份对照表被判不可用，原话在 `docs/项目适配包.md` **§6** 的表格：「其余文档（`docs/调研/**`、飞书摘要、旧方案稿）—— **一律不作依据**」。§3.2 是「已删资产」清单。两处指向同一结论：**本模板不得作为验收依据、不得写进「已实现」的证明**。
- 保留理由（所有者 2026-10-29 原话）：「你的 7 段也可以作为一个可选择的版本吧？万一你的 7 段有用呢」——**留着，但必须挂着这个牌子**。
- 因此：下面每一段的 `原文依据` 一律写「无」。**不补、不借、不拿 C2 的历史提示词冒充甲方成品**（C2 的转录本身就出自那份不作依据的文档）。

## 适用场景

- 想试「先产品后场景、机制单列」这种讲法时用它。它的卖点是**把机制从分镜里提出来单独说**，适合一条片子只有一个机关、且这个机关需要被讲清楚的场合（如换装、跃出、拉伸）。
- 需要一段**独立的否定式约束**收尾（模板 A 里这段只有 1/17 命中，这里给了固定位置）。
- **不适用 / 慎用**：客户要「甲方认的格式」时——直接看原例就露馅，甲方用的是 ✅ 清单式（见 `templates/employee-checklist.md`）；需要证据链时——本模板任一段都拿不出原文。
- 若与模板 A 同时可读，**默认选 A**（A 有 17 条范例逐条计数支撑）；本模板只在明确想换讲法时启用。

## 段落定义

### 第 0 段：0 总述

- 写什么：一行到三行，把**全片参数**一次说清——`总时长`、`画幅`、`单镜头 / 多镜头`、`风格一句话`、`情绪一句话`。它是给后面六段定基调的，不展开画面细节。
- 数据来源：`九层 七（分镜表）` → 总时长与镜头数；`九层 五（镜头）` → 单镜头/多镜头；`九层 六（意境）` → 风格与情绪。**画幅不在九层**，取自项目参数。
- 口吻：名词短语 + 键值句，一行一条，不铺陈、不给理由。允许一句祈使（「生成单镜头」），但整段以陈述为主。
- 原文依据：无。

### 第 1 段：一 产品参考

- 写什么：① 产品外观的**唯一依据声明**（哪张图、只借什么）；② 形状/标签/比例三项**不可变**；③ `@图片N` 与产品的绑定关系；④ 明确「不参考该图的背景、人物、场景」。
- 数据来源：`九层 二（产品）` → 形状 / 标签 / 比例 / 标签文字；`九层 九（资产）` → `@图片N` 绑定关系与可用资产清单。
- 口吻：陈述 + 一句强约束（「严格保持…」）；引用图号用 `@图片N`，不写「第一张图」这类自然语言（图号即契约）。
- 原文依据：无。

### 第 2 段：二 场景构图光线

- 写什么：① 环境（室内/室外、材质、墙面、背景层次）；② 陈设与道具（只写看得见的形状与位置）；③ 机位与构图（高度、角度、景别、主体在画面里的位置）；④ 光线（光质、方向、色温、有无硬阴影）。
- 数据来源：`九层 一（场景）` → 环境与陈设；`九层 五（镜头）` → 机位/角度/景别/构图；`九层 四（光影）` → 光质/方向/色温。
- 口吻：陈述式，空间关系写「画面左/右/上/下」这类**画面坐标**，不写「旁边」「不远处」这种相对含糊词。
- 原文依据：无。

### 第 3 段：三 核心机制

- 写什么：一条片子只写**一个**机关，四件事——① 触发（什么动作/什么时刻启动）；② 变化过程（物体怎么变、沿什么轨迹）；③ 落定状态（变完是什么样）；④ 时间位置（第几秒到第几秒）。多机关时拆成 `3.1 / 3.2` 子条，不新开段。
- 数据来源：`九层 三（运动）` → 轨迹、周期、变化过程；`九层 七（分镜表）` → 该机制发生的时间位置；`九层 二（产品）` → 变化前后产品状态的差异。
  - ⚠️ **九层里没有「机制」这一层**。这一段是把 `三（运动）` + `七（分镜表）` 拼出来的**派生结论**，不是某一层的直接字段。这是本模板与九层 IR 唯一的结构性错位——也是它「没有甲方依据」的具体表现之一。
- 口吻：陈述 + 动词驱动（「叶片先加速，再整片脱离轴心向外甩出」）；**不解释原理**、不写「因此显得很酷」这类评价。
- 原文依据：无。

### 第 4 段：四 逐秒分镜

- 写什么：按时间切段，每段一行或一小块——`时间码（起–止）` + `画面动作` + `产品状态` + `镜头是否动`。段数与参考片的**状态变化次数**对齐（±1 容差）。动作写连续动作链，不写转场评价。
- 数据来源：`九层 七（分镜表）` → 段数与时间码；`九层 三（运动）` → 每段的动作与轨迹；`九层 一（场景）` → 每段所在环境；`九层 二（产品）` → 每段产品可见性与状态。
- 口吻：陈述句、现在时、动词开头；一条动作一句；时间码通篇一种格式（`00:00–00:03`），不混用。
- 原文依据：无。

### 第 5 段：五 声音

- 写什么：四块，缺一不可——① **台词**：有/无，有则语种 + 逐句原文 + 说话人；② **音效**：点对点挂在动作上（哪个动作配什么声）；③ **BGM**：有/无，有则风格与配器；④ **环境声**：留什么、压什么。
- 数据来源：`九层 八（声音）` → 台词 / 音效 / 音乐 / 环境声；`九层 七（分镜表）` → 音效与画面的对齐时刻。
- 口吻：指令式（「加入…」「保持…」「不加…」）——这是全篇唯一可以连续用祈使句的段。
- 原文依据：无。

### 第 6 段：六 全程约束

- 写什么：否定式清单，五类——① 产品不许变形/变色/标签漂移；② 人物不许换脸/换装/多手指；③ 镜头不许推拉摇移（若定死一镜到底）；④ 不许加人、加道具、加字幕、加品牌标识；⑤ 时长与画幅不许变。
- 数据来源：`九层 九（资产）` → 一致性清单（同一人物/同一产品）；`九层 二（产品）` → 产品不可变形；`九层 五（镜头）` → 机位锁定；`九层 三（运动）` → 转场方式刚性。
- 口吻：纯否定 + 强制（「不得」「不能」「必须」「不许」）；只写**不想要的**，不重复前五段已写明的正向内容。
- 原文依据：无。

## 可选段

### 可选段 C：七 品牌收束（第十层「图文与收束」）

- 写什么：一段收束与图文登记——收束类型（品牌字定格板 / 产品与品牌字同框 / 字幕标语收束 / 无品牌露出 / 其他照实写）、版式（谁居中、谁在上、谁压着谁、背景是什么）、动效时序（谁先出现、大约几秒、怎么动）；全片持久性文字/标识（品牌字、标语、字幕、角标、水印、包装上的字）逐条登记。**品牌字位一律写「客户品牌字样」占位**——借创意不复刻品牌，参考片原字一个不写；参考图用 `@图片N` 指代并只带 2–6 字典型说明。全片没有持久性文字就写「图文：无」。
- 数据来源：`十层 十（图文与收束）` → 收束类型/版式/动效时序；图文元素逐条
- 字样置换：是
- 口吻：否定式与陈述式并用；「图文：无」与「不加字幕、不加品牌标识」是同一件事的两种写法，不重复列。
- 原文依据：无。
- 渲染建议：拆解有「十 图文与收束」层时开这一段（`--optional C`）；旧九层拆解没有这一层，保持关闭。

## 空段规则

- 某段在 IR 里没有素材（如全片无台词）→ **保留标题，正文写「无」**，不删小节、不留空行。
- 「无」只用于**该段整体无内容**；若只有子块无内容（如无 BGM 但有音效），写 `BGM：无`，不写整段「无」。
- 不得用「不适用」「略」「同上」代替「无」。

## 已知缺陷（用之前先知道）

1. **零原文依据**：七段全部拿不出甲方原文，与模板 A 的「17 条逐条计数」不在一个证据等级上。
2. **与九层有一处错位**：「三 核心机制」没有对应的 IR 层，需要渲染侧做派生（见上）。模板 A 与模板 B 都是「一层对一段或数段」的直取，没有这个问题。
3. **段落序号从 0 起**：`0 总述` 与 `templates/README.md` §5「N 从 1 连续」的校验规则冲突；若启用本模板，渲染器的段号校验需允许起始 0。
4. **标题是中文序号**（`一 产品参考`），不是 `第 1 段`。渲染器应按标题行逐字匹配，不能按 `第 N 段` 正则切。
