# 模板 D · 时段叙事体

## 出处与可信度（先看这段）

- **唯一依据**：`docs/原提示词-抄录.md` —— 甲方给这条片子亲手写的成品提示词，正文逐字抄录（原件 35 行）。
  这不是「我们猜甲方喜欢什么格式」，是甲方真正拿去出片的那份文字（所有者 2026-11-01 裁定：甲方一手件优先级高于范例库）。
- **照它抄的四件事**：① 开头一段总述定风格；② 一句「一镜到底、无剪切」钉住连续性；③ 每个时段一句长句，时间码开头，
  人 / 物 / 位置 / 朝向 / 视线 / 运动 / 镜头 / 画面一次说完；④ 末尾一条全片约束。
- **不抄的**：表格、字段名（正文里不出现「站位：」这类列名回显）、JSON、参数位（`--ar` / seed / 负面词表）——原件里 0 处。
- **图号写在句内**：原件的写法是「模特 @图片1 穿着这套服装 @图片4」，图号跟着人走，不做行首标签。
- **样本量 = 1 条**。所以本文件不写「N/N 条都这样」：只有一条，就说一条；本模板是**第四种口味**，与 A/B/C 并存，
  不替它们，也不改它们的基线。

## 适用场景

- 单条 8–16 秒、**一镜到底或有明确时段节拍**的创意短片（特效、变装、破屏、递物）。
- 生成端吃**连续叙事文本**、按时间码理解节拍（甲方这条片子用的就是这种写法）。
- 需要把**空间调度**说清楚：人在画面哪个位置、身体朝哪边、眼睛看哪里、占多大——这正是前三版最容易丢的部分。
- 不适用：多机位对剪的剧情片（本模板默认一镜到底）；需要逐句台词语种对位的口播带货（用模板 B）；
  需要风格 / 摄影 / 分场 / 声音四段式结构化的场合（用模板 A）。

## 段落定义

### 第 1 段：一句话总述与影调

- 写什么：开场四句，一句一条——① 这条片子要让观众记住的那一件事（用什么把人带进去）；② 明暗与冷暖：硬调还是柔调、暖还是冷、影子是硬边还是散开的；③ 时间的松紧：哪一秒是重音、收尾是减速还是定格；④ 全片情绪基调：什么情绪、有没有走向。只取拆解原文，不改写、不补形容词。
- 数据来源：`九层 六（意境）` → 一句话、情绪基调与松紧；`九层 四（光影）` → 明暗与冷暖
- 口吻：陈述句、现在时，一条一句，20–60 字；纯描述，不出现「请」「需要你」「建议」。
- 原文依据：docs/原提示词-抄录.md §1

### 第 2 段：时段叙事（一句一条）

- 写什么：每个时段一句，时间码开头：先给景别，再说清主体（图号紧跟）、站位、朝向、视线，接镜头运动，最后是画面内容；镜头给人的感受（如「电影感」「很震撼」「极具冲击力」）与灯光质感写在该时段句里，帮视频模型理解调性。列序由本段的 `分镜列` 声明，一句到底，不出现列名，不写转场（一镜到底没有剪切点）。
- 数据来源：`九层 七（分镜表）` → 分镜 13 列逐镜取值
- 分镜列：时段,景别?,运动主体,运动形态,情绪/表演?,站位?,朝向?,视线?,镜头运动?,画面内容
- 口吻：陈述句、现在时、动词驱动；一句到底，句内只用「，」，不用分号与竖线；时间码写在句首、格式与拆解一致。
- 原文依据：docs/原提示词-抄录.md §3

### 第 3 段：全片连续性与首帧

- 写什么：两条全片不变的约束——① 全片是否一镜到底、有没有剪切点；② 第 0 秒的起始状态：画中的人站在哪个方位、占多大、身体朝哪边、视线落在哪。写到「是 / 否」与具体方位为止，不解释理由。
- 数据来源：`九层 七（分镜表）` → 一镜到底判定与首帧行
- 口吻：陈述句；两条各占一行，一行给判定、一行给起始状态；不带形容词，不解释为什么这么拍。
- 原文依据：docs/原提示词-抄录.md §2

### 第 4 段：声音与收尾

- 写什么：三句——① 台词状态（有没有、什么语种、逐句大意）；② 音乐的骨架：风格、配器、第几秒有重音；③ 音效挂点：每个关键瞬间对应什么声音。没有的写「无」，不编。
- 数据来源：`九层 八（声音）` → 台词 / 音乐 / 音效
- 声音段：是
- 口吻：名词短语 + 数值；音效点写成「第 N 秒 + 声音」；不用祈使句，不写「建议加…」。
- 原文依据：docs/原提示词-抄录.md §1（原件只有「配合电子科幻Pop/Funk风格音乐」一句；台词与音效是本项目按拆解 IR 补齐的，不冒充原文）

## 可选段

### 可选段 C：品牌收束与图文（第十层「图文与收束」）

> 字母语义全局统一（2026-11-05，与 lumi-4section 对齐）：A=前置总述 / B=全程约束 / **C=品牌收束与图文**。本模板只有 C 一个可选段（范例证据只有收束段，不造 A/B）。

- 写什么：段 4 之后接一行收束——收束类型（品牌字定格板 / 产品与品牌字同框 / 字幕标语收束 / 无品牌露出 / 其他照实写）、版式（谁居中、谁在上、谁压着谁、背景是什么）、动效时序（谁先出现、大约几秒、怎么动），全片持久性文字/标识逐条带上。**品牌字位一律写「客户品牌字样」占位**——借创意不复刻品牌，参考片原字一个不写；参考图用 `@图片N` 指代并只带 2–6 字典型说明。全片没有持久性文字就写「图文：无」。
- 数据来源：`十层 十（图文与收束）` → 收束类型/版式/动效时序；图文元素逐条
- 字样置换：是
- 口吻：陈述句、现在时，一条一行；收束三件套写完即收。
- 原文依据：docs/原提示词-抄录.md §3（原件分镜末段「…镜头升格，模特融入虚拟数字空间，四周被大量的产品呈立体悬浮状包围，最终定格于仰拍中景（人物位于画面下方二分之一）。」——收束就是定格，无品牌露出；照这个口径写）
- 渲染建议：拆解有「十 图文与收束」层时开这一段（`--optional C`）；旧九层拆解没有这一层，保持关闭。

## 与前三版的差异

| 维度 | 本模板（时段叙事体） | 模板 A · Lumi 四段 | 模板 B · 甲方清单式 | 模板 C · 七段 |

| 粒度 | 一句一个时段 | 一段一主题 | 一行一件事 | 七段，段内可长可短 |
| 分镜怎么出 | `分镜列` 挑列，一句一条 | 逐列倒出（`列名：值`） | 逐行倒出 + 台词行 | 逐列倒出 |
| 空间调度 | 站位 / 朝向 / 视线 / 景别进句子 | 不单列（靠分镜行原样） | 只有「腰部以上中景」一句 | 不单列 |
| 图号位置 | **句内**，紧跟主体 | 行首前缀 | 行首前缀 | 行首前缀 |
| 转场 | 不写（全片一镜到底） | 写在场景开头 | 写进「镜头」行 | 独立段 |
| 声音 | 末尾一段 | 段 4 | 拆进口播行与台词行 | 独立一段 |

## 渲染器行为注记（改本文件前先读）

1. **`分镜列` 是本模板的核心指令**：段 2 写了 `- 分镜列：…` 之后，该段把「七 分镜表」按声明顺序取列、用「，」连成一句，
   每个镜号一行；空值 / `—` / `无人物` 的列直接跳过；`运动主体` 那一列的 `@图片N` 紧跟在主体值后面（不是行首）。
   声明的列名在表头里不存在，渲染器直接 exit 3 报「模板要的列 X 拆解里没有」——**不静默跳过**。
   列名可写 `时段`（自动对到表头的 `起秒-止秒`）与 `镜号`（对到 `镜号` / `#` / `序号`）。
2. **段 1 与段 3 的 `写什么` 刻意不含维度词**（不写「光」「场景」「人物」「位置」「节奏」「镜头」这类词）。
   渲染器按维度过滤子块：`写什么` 里出现维度词，就只收该维度的子块，而「六 意境」「一 场景」这两层的子块
   标签本身推不出维度，会被整块挡在外面，这两段就变成「无」。改这两个字段前先读 `render.py` 的
   `dims_of_section()` 与 `DIMENSIONS`。
3. **不要写 `- 范例证据：`**。本模板的依据是甲方一手件，一律用 `- 原文依据：docs/原提示词-抄录.md §N`；
   写了 `范例证据` 会切到「≥3 条且必须在 library/examples 命中」的校验分支，直接 exit 3。
4. **正文不出现产品名**：产品一律用 `@图片N` 指代，名字只在资产清单里出现一次（项目硬约束 7 的同一条纪律）。
5. 段落顺序即渲染顺序：段 2 必须早于段 3——段 2 消费分镜行，段 3 只拿同层剩下的「一镜到底」「首帧」两块。
   把段 3 挪到段 2 前面，段 3 会把整张分镜表当普通子块倒出来（表格行原文），叙事体就废了。
